# jjb's updates

jjb reads this folder so she can tell people what changed about her.

Every pull request that changes what people notice about jjb (a new feature, a change in how she talks,
something she stopped doing) adds one file here:

- Name: `YYYY-MM-DD-short-name.md`, using the date of the change.
- Content: one or two plain sentences, written for people in the server. No code words.

One file per change keeps pull requests from clashing. Fixes nobody would notice don't need one.
